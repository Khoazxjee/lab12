# Lesson 12 – Lab 5 và Lab 6

Hai project ASP.NET Core MVC kế thừa project Code First của Lab 4.

| Project | Nội dung | Địa chỉ khi chạy |
| --- | --- | --- |
| Lab5 | Lọc người học theo ngành bằng tải lại trang hoặc AJAX | http://localhost:5116/Learner |
| Lab6 | Phân trang 3 người học mỗi trang, kết hợp lọc ngành và tìm theo tên | http://localhost:5117/Learner |

Mở `Lab5_Lab6.sln` bằng Visual Studio 2022, chọn Lab5 hoặc Lab6 làm startup project rồi nhấn Ctrl+F5. Máy cần .NET SDK 8 và SQL Server. Hai lab dùng chung cơ sở dữ liệu thực hành; xem [hướng dẫn cấu hình và chạy thử](HUONG_DAN_LAB5_LAB6.txt).
